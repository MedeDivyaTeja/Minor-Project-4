#  Credit Card Fraud Detection using Unsupervised Learning

## 📌 Overview

A Python-based Machine Learning project focused on detecting potentially fraudulent credit card transactions using **Unsupervised Learning** techniques.

The project explores **K-Means Clustering** and **Isolation Forest** to identify transaction patterns and detect anomalies in a highly imbalanced dataset.

## 🎯 Objectives

* Perform Exploratory Data Analysis (EDA)
* Preprocess and standardize transaction data
* Apply K-Means Clustering
* Apply Isolation Forest for anomaly detection
* Evaluate the detected anomalies using fraud labels

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* K-Means Clustering
* Isolation Forest
* Google Colab

## 📊 Dataset

The project uses a credit card transaction dataset containing **284,807 transactions and 30 features**, with fraudulent transactions representing a very small portion of the data.

## 📈 Key Learning

This project helped me understand **unsupervised learning, anomaly detection, data preprocessing, class imbalance, and model evaluation** in a real-world fraud detection scenario.
